03 / One notice, participating engines

Send an IndexNow ping

IndexNow shares a single URL-change notice with participating search engines. Current participants include Bing, Naver, Seznam and Yandex; the official list can change. You must own the site and publish the matching key file before sending.

Use the public verification key from the file named YOUR_KEY.txt in your site root. If your key file lives elsewhere on the same site, provide its full URL. This is not an account password.

Read IndexNow protocol and key requirements ↗ · Bing setup walkthrough ↗

Opens the official IndexNow endpoint in a new tab only after you click. A successful receipt means the notice was accepted—not that the page was indexed.

04 / AI-powered discovery

There is no universal AI submit button

AI search products mostly discover pages through their search indexes, their own search crawlers, or a user-requested fetch. Keep those routes open and make useful pages easy to understand.

05 / Technical readiness

Make the site worth finding

These checks help crawlers fetch, interpret, and trust the page. They improve eligibility; no checklist can force an index or citation.

01
Return a public 200 responseImportant pages should load without a login, CAPTCHA, or blocked JavaScript-only rendering.
02
Remove accidental noindex blocksReview robots.txt, meta robots, canonical tags, CDN bot rules, and page-level access settings.
03
Publish a real XML sitemapList canonical URLs, link the sitemap in robots.txt, and submit it in verified webmaster consoles.
04
Write clear, useful page contentSay what the product is, who it helps, how it works, and what is distinctive—in crawlable text.
05
Use accurate structured dataOrganization, WebSite, or SoftwareApplication markup can clarify entities when it matches visible facts.
06
Earn relevant independent mentionsKeep your name and facts consistent; pursue genuine reviews, community references, and useful directories—not spam submissions.
